## How to Run the Exercises

Many exercises are independent from each other. For that reason, navigate into the relevant folder before compiling or running a program.

### Running C Programs

Compile a single C file using `gcc`:

```bash
gcc file_name.c -o program
./program
```

For projects with multiple C files:

```bash
gcc main.c helper.c -o program
./program
```

### Running C++ Programs

Compile a single C++ file using `g++`:

```bash
g++ -std=c++11 file_name.cpp -o program
./program
```

For projects with multiple C++ files:

```bash
g++ -std=c++11 main.cpp ClassName.cpp -o program
./program
```

### Running Java Programs

Compile and run a Java file:

```bash
javac Main.java
java Main
```

For folders with multiple Java files:

```bash
javac *.java
java Main
```

Replace `Main` with the class that contains the `main` method.

### Running Haskell Programs

Run a Haskell file with:

```bash
runghc file_name.hs
```

Or load it in GHCi:

```bash
ghci file_name.hs
```

### Running Prolog Programs

Run a Prolog file using SWI-Prolog:

```bash
swipl file_name.pl
```

Then enter queries in the Prolog interpreter.

### Running Python Programs

Run a Python file using:

```bash
python file_name.py
```

or:

```bash
python3 file_name.py
```
