# University

This folder contains a simple Java console application for practicing object-oriented programming through a university example.

The project models people in a university system using separate classes such as `Person`, `Student`, and `Instructor`. It also includes both Java source files and compiled Java class files.

## Files

```text
University/
│
├── Instructor.java
├── Person.java
├── Student.java
├── University.java
├── Instructor.class
├── Person.class
├── Student.class
├── University.class
└── README.md
```

## Overview

The project is based on a simple object-oriented structure.

A general `Person` class is used to represent common information shared by people in the university system. More specific classes such as `Student` and `Instructor` represent different roles.

The `University` class contains the main program logic and is the class that should be executed to run the application.

## Main Concepts Practiced

This exercise is useful for practicing the following Java concepts:

* Classes and objects
* Constructors
* Encapsulation
* Getter and setter methods
* Inheritance
* Method overriding
* Class relationships
* Console-based Java programming
* Compiling multiple Java files
* Running compiled Java programs

## Class Descriptions

### `Person`

`Person` represents the general structure of a person in the university system.

It is used as the base class for more specific person types such as students and instructors.

Common information may include details such as:

* Name
* Surname
* ID
* Other shared person-related attributes

### `Student`

`Student` represents a student in the university system.

It specializes the general `Person` structure and is used for student-related information and behavior.

### `Instructor`

`Instructor` represents an instructor in the university system.

It specializes the general `Person` structure and is used for instructor-related information and behavior.

### `University`

`University` is the main class of the project.

It contains the `main()` method and runs the application.

## Source Files and Class Files

This folder contains both `.java` files and `.class` files.

### `.java` Files

`.java` files are the original Java source code files.

These are the files that should be edited when changing the program.

```text
Instructor.java
Person.java
Student.java
University.java
```

### `.class` Files

`.class` files are compiled Java bytecode files.

They are generated when the `.java` files are compiled using the Java compiler.

```text
Instructor.class
Person.class
Student.class
University.class
```

These files can be regenerated by running:

```bash
javac *.java
```

Because `.class` files are generated from `.java` files, they usually do not need to be edited manually.

## How to Run

Open a terminal inside the `University` folder.

Compile the Java source files:

```bash
javac *.java
```

Run the program:

```bash
java University
```

## Example Commands

From the main repository folder:

```bash
cd Java/University
javac *.java
java University
```

## Notes

The `.java` files are the important editable files. The `.class` files are compiled outputs that can be recreated whenever the source files are compiled again.
